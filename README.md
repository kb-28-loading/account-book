## 📝 프로젝트 소개
**Loading**은 사용자의 수입과 지출을 직관적으로 관리하고, 목표 예산을 설정하여 스마트한 소비 습관을 기를 수 있도록 돕는 웹 기반 가계부 서비스입니다. 보라색(#bfa5d4) 테마를 바탕으로 금융 데이터를 한눈에 파악할 수 있는 UI를 제공합니다.

<br/>

## ✨ 주요 기능
- **🗓️ 반응형 달력 뷰**: 월별 수입/지출 내역 확인 및 말줄임표 처리.
- **💰 거래 내역 관리**: 날짜별 내역 조회, 정렬, 페이지네이션 및 CRUD 기능.
- **🎯 목표 예산 설정**: 카테고리별 예산 설정 및 실시간 잔액 확인.
- **📱 반응형 레이아웃**: 디바이스 크기에 최적화된 컴포넌트 배치.

<br/>

## 🛠️ 기술 스택
- **Frontend:** Vue 3 (Composition API), Pinia, Vue Router, Bootstrap 5, fontawesome
- **Backend:** JSON Server (REST API)
- **Design:** Figma

## 🚀 시작하기

### 1. 패키지 설치
`npm install`
`npm install chart.js vue-chartjs`

### 2. 서버 실행
`json-server db.json`
`npm run dev`
